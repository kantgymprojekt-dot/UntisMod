# Source XAPK reference

The UI resources in this iOS project are sourced from the uploaded `Untis 6.8.3.xapk`, not from the uploaded IPA ZIP.

Verified package metadata:
- Package: `com.grupet.web.app`
- App name: `Untis`
- Version: `6.8.3`
- Version code: `2467`
- XAPK manifest icon: `icon.png` (512 × 512), used as the iOS AppIcon source.

`OriginalAPKParts/` contains the APK splits extracted from this exact XAPK. They are preserved for reference only and are not added to the iOS app target. `ResourceInventory.json` inventories the base APK from the same XAPK. `XAPK_Manifest.json` and `SHA256SUMS.txt` record source identity and hashes.

The current XAPK's base APK SHA-256 is identical to the earlier 6.8.3 base APK, so its drawable and layout resources match that package. This project nevertheless records the current XAPK upload as the sole resource source for this revision.
