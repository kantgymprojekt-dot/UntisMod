# Android source reference

These APK splits are preserved as reference-only inputs. They are intentionally not added to the iOS app target or copied into the iOS bundle.

- `com.grupet.web.app.apk`: base package, version 6.8.3, versionCode 2467.
- `config.de.apk`: German language configuration split.
- `config.tvdpi.apk`: TVDPI resource configuration split.

The uploaded standalone APKs were byte-identical to their matching APK splits in the uploaded XAPK, based on SHA-256. This means the standalone files did not add a different/newer build, but they are valid 6.8.3 source files.
